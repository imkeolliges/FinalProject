# Lyric Spark
A tool for creatives to get inspired while writing lyrics 
Including:
- One box for writing down lyrics
- A word counter
- Two buttons for receiving either matching rhymes / synonyms

# Installation
Clone the repository and import:
- import requests
- import streamlit

# How to run
- streamlit run app.py
But also consider all of the other files are in place beforehand

.streamlit including config.toml >>> relevant for the background colour
.gitignore >>> to make it run
app.py >>> main code
